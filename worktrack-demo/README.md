# WorkTrack Web Demo

نسخة ويب تجريبية لتقييم واجهات نظام الحضور والانصراف وتتبع مواقع العمال.

## الدخول

- رقم الموظف: `1001`
- كلمة المرور: `123456`
- يمكن اختيار دخول عامل أو إدارة.

## ملاحظات

- تستخدم النسخة GPS الحقيقي من المتصفح بعد منح الإذن.
- موقع المشروع التجريبي في المدينة المنورة بنطاق 250 مترًا.
- بيانات لوحة الإدارة تجريبية، وتسجيل الحضور يحفظ محليًا داخل المتصفح.
- النسخة الإنتاجية ستبنى بـ Flutter وتربط بـ Firebase والتنبيهات الخلفية.
